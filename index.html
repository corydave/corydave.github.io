How I Build OER

Open Source Workflows for Open Textbooks

Proprietary publishing systems lock content inside gated content-management silos. I build educational resources using modern, text-based, version-controlled developer tooling.

Collaborative Remixer Friendly

Any teacher can submit a typo fix, translate a chapter, or fork an entire semester of assignments with standard Git Pull Requests.

MD

Markdown & Quarto

Plain text files that compile into beautiful responsive web books, ePubs, accessible PDFs, and slides seamlessly.

GIT

Public Git Repositories

Transparent commit history, peer review through PRs, and community-driven curriculum maintenance.

H5P

Interactive Formative Quizzes

Self-hosted interactive practice widgets that students run directly inside their browsers without data tracking.

A11y

WCAG 2.1 AA Compliance

Alt-text for all diagrams, high-contrast mathematical notation via MathJax, and dyslexia-friendly typography.
